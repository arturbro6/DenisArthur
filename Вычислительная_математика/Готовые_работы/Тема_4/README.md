## Самый простой запуск

Скачайте `index.html` и откройте двойным щелчком в браузере. Интернет и установка библиотек не нужны. Выберите задачу, метод, число частей и нажмите **Рассчитать**. Кнопка **Скачать CSV** выгружает всю таблицу, включая начальную точку.

В интерфейсе численное ядро написано на JavaScript. Оно реализует те же формулы, что и `main.py`; результаты обоих вариантов сверены.

## Запуск Python

Требуется Python 3, внешние пакеты не нужны.

```sh
python3 main.py          # интерактивное меню
python3 main.py --all    # пересчитать всю работу и создать CSV/SVG/JSON
python3 main.py --check  # проверить численное ядро
```

Для больших сеток интерактивная консоль показывает первые и последние строки; полный результат сохраняется в `results/interactive.csv`. Уточнённый Эйлер для примеров 1 и 2 сохраняется в исходных 11 узлах сравнения.

## Примеры и опечатки в исходном задании

| Пример | Условие | Основная сетка и дополнительные расчёты |
|---|---|---|
| 1 | y′ = y(1−x), y(0)=1, [0;1] | n=10; уточнение Эйлера до расхождения с РК4 ≤ 10⁻⁵ в исходных узлах |
| 2 | y″+y′/x+y=0, y(1)=0,77, y′(1)=−0,44, [1;1,5] | n=10 даёт h=0,05; отдельно рассчитан указанный h=0,1 (n=5) |
| 3 | x′=−2x+5z; y′=sin(t−1)x−y+3z; z′=−x+2z; (2,1,1), [0;0,3] | Эйлер при n=10,100,1000: h=0,03;0,003;0,0003 |

В первой строке системы в условии повторяется `dy/dt`; принято `dx/dt`, поскольку иначе отсутствует уравнение для x. Эти допущения явно указаны в отчёте.

Контрольное решение РК4 с n=10000 — численный эталон, а не точное решение. Для примера 1 известно точное решение `exp(x−x²/2)`.

## Коротко для защиты

- Метод Эйлера: новый вектор равен старому плюс шаг, умноженный на правую часть. Все компоненты обновляются одновременно.
- РК4: четыре вычисления правой части на одном шаге; итоговая взвешенная сумма имеет коэффициенты 1,2,2,1.
- Второй порядок сводится к системе заменой v=y′.
- Глобальная ошибка Эйлера — O(h), классического РК4 — O(h⁴).
- Одинаковая сетка: РК4 точнее. Уменьшение шага улучшает Эйлера, но увеличивает число вычислений.
