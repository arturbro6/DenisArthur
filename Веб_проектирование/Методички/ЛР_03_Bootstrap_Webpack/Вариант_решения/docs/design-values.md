# Измерения макета

Эту таблицу нужно заполнить по Pixso. Пример _theme.scss не является результатом измерений.

| Элемент / состояние | Свойство макета | Измеренное значение | SCSS-переменная | Проверка после сборки |
|---|---|---|---|---|
| Закрытый пункт | Фон | | $accordion-bg | |
| Открытая кнопка | Фон | | $accordion-button-active-bg | |
| Открытая кнопка | Текст | | $accordion-button-active-color | |
| Граница | Цвет | | $accordion-border-color | |
| Контур | Скругление | | $accordion-border-radius | |
| Кнопка | Отступ по горизонтали | | $accordion-button-padding-x | |
| Кнопка | Отступ по вертикали | | $accordion-button-padding-y | |
