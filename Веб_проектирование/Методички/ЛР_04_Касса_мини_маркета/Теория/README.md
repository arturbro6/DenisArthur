# JavaScript с нуля для этой работы

## Где вводить

Код функции вводится в HTML-файле в VS Code внутри существующего script, на месте заглушки task. Команды запуска Node вводятся в терминале. Вызовы window.task вводятся в Console браузера (Инструменты разработчика). Результат читается на странице или в консоли; текст результата не нужно вставлять обратно в код.

Файл HTML — страница. HTML-форма уже готова; JavaScript считает заказ. Функция не должна показывать alert или самостоятельно записывать HTML: она возвращает объект, а шаблон показывает его.

## Функция, объект, свойство

```javascript
function example(order) {
  return order.items.notebook * 250;
}
console.log(example({ items: { notebook: 2 } }));
```

function объявляет функцию, example — имя, order — входной параметр. Фигурные скобки после объявления ограничивают тело. return возвращает результат и прекращает вызов. Здесь в консоли будет 500. Объявление функции само по себе её не запускает.

Объект — набор названных полей: `{price:250,stock:8}`. Двоеточие отделяет имя от значения, запятая — свойства друг от друга. `catalog.notebook.price` — цена тетради. Если имя товара хранится в переменной code, пишем `catalog[code].price`, иначе catalog.code искал бы буквальное поле code.

## Переменные и сравнения

| Запись | Значение |
|---|---|
| const count = 2; | Создать имя, которое не будет переназначаться |
| let subtotal = 0; | Создать переменную, значение которой будет меняться |
| subtotal += 250; | То же, что subtotal = subtotal + 250 |
| === / !== | Строго равно / не равно, без превращения строки в число |
| !условие | Отрицание |
| a && b | Оба условия истинны |
| a || b | Достаточно одного истинного условия |
| if (...) { ... } | Выполнить блок, если условие истинно |
| continue; | Перейти к следующему проходу цикла |
| // комментарий | Пояснение до конца строки |

`"2"` — текст, `2` — число. `Number.isInteger("2")` даёт false, а Number.isInteger(2) — true. Не превращайте строковые количества в числа внутри task: тип проверяет условие. Преобразование URL в объект делает шаблон. true и false — логические значения, без кавычек, маленькими буквами.

## Цикл по товарам

```javascript
for (const code in order.items) {
  const count = order.items[code];
}
```

for...in перебирает строковые имена свойств. Для items={notebook:2,marker:1} code по очереди обозначает notebook и marker. Каждое количество читается через квадратные скобки. В реализации перед расчётом проверяется собственность поля, чтобы не обрабатывать поля, унаследованные через прототип.

```javascript
const owns = (object, key) => Object.prototype.hasOwnProperty.call(object, key);
```

Это короткая вспомогательная функция: (object,key) — два параметра, => — вернуть выражение справа. Её вызов owns(catalog,code) даёт true только для собственного поля каталога. Так имена toString, constructor и __proto__ не станут допустимыми товарами. Вызов через Object.prototype работает даже если объект имеет собственное поле hasOwnProperty. Классы и подробное устройство прототипов для решения не нужны: здесь это надёжная проверка наличия товара.

## Числа и округление

`Math.floor(x)` округляет вниз. Скидка = floor(subtotal / 10), потому что 10% = одна десятая. Не округляем итог и не вычитаем 10 рублей. Для текущих цен сумма всегда кратна 10, но floor оставляем как прямое выполнение правила.

Сначала subtotal, затем discount, затем afterDiscount, затем delivery, затем total. При четырёх тетрадях STUDENT даёт afterDiscount=900, поэтому доставка 150 и итог 1050. Если проверить порог на subtotal=1000, получится ошибка.

## Возвращаемый объект

`{ok:true,subtotal}` — сокращение `{ok:true,subtotal:subtotal}`. Нужны числа в денежных полях, а не строки с символом рубля. При ошибке возвращаем только ok и error. `console.log` помогает проверять, но не заменяет return.

Вход не изменяется, если мы только читаем order и записываем собственные локальные переменные. Не делать order.total=..., delete order.items..., order.items[code]--. Каталог создаётся внутри вызова и не расходуется; одинаковые заказы дают одинаковые ответы.
