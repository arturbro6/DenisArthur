# Сортировка

[Оригинал в Moodle](https://moodle.herzen.spb.ru/mod/scorm/view.php?id=1114900).

Статус: точное условие проверятора ещё не извлечено. Первый SCORM-проверятор открывается, но встроенный сайт kodaktor.ru возвращает ERR_TIMED_OUT. Поэтому рабочий интерфейс, имена функций и формат ответа не выдуманы; готовое решение не заявляется.

Порядок разбора после восстановления доступа:

1. Открыть SCORM и сохранить точную постановку, пример входа и ожидаемый выход.
2. Выписать типы аргументов, имя функции и ограничения на реализацию.
3. Решить минимальный пример вручную.
4. Написать функцию и проверить обычные, граничные и ошибочные входы.
5. Сверить формат результата с проверятором; сохранить исходный код и реальный результат проверки в `Готовые_работы/Чеки/Чек_04`.

Общие темы для подготовки: типы JS и преобразование строк в числа; `return`; условие `? :`; числовой компаратор `sort((a,b)=>a-b)`; разница `**` и побитового `^`. Эти темы не заменяют неизвестное условие этого чека.
