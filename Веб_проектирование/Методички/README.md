## Как работать

В каждой работе:

- `Условие.md` — пересказ требований и ссылки на оригиналы;
- `Теория/README.md` — необходимые понятия и объяснение незнакомых конструкций;
- `Вариант_решения/Пошаговый_гайд.md` — последовательность действий, ручные примеры, проверки и вопросы для самостоятельной работы;
- рядом с гайдом — учебный код и, где применимо, тесты и незаполненные журналы.

Прочитайте условие, попробуйте составить собственный план, затем идите по шагам. После каждого изменения объясните, зачем оно нужно, и проверьте результат. Учебный пример требует выбора своего варианта, запуска в своей среде и оформления фактических результатов. Страницы Moodle остаются источником требований: преподаватель может их обновить.

Полные чужие лекции и PDF не перепечатываются: здесь собственные пояснения, пересказ условий и ссылки на материалы. Незаполненные таблицы не являются утверждением о выполненных экспериментах.

## Варианты заданий

Для каждой из трёх лабораторных прочитаны задания контрольной и экспериментальной групп. В условии разделены общие требования и дополнительные действия экспериментальной группы. Журналы запросов и разбор предложений нужно заполнить по собственному выполнению.

В третьей работе значения темы SCSS демонстрационные: цвета и размеры по Pixso предстоит измерить самостоятельно. Два каталога с кодом — последовательные состояния проекта. Пример Pages хранится как `.yml.example`, поэтому сам по себе не публикует сайт общего репозитория.

[Другие элементы курса](Проверяторы/README.md) перечислены отдельно: они не выдаются за разобранные лабораторные.
