# Два этапа общей задачи

**Этап 1:** собрать только контейнеры и сетку Bootstrap 5.3. Не подключать полный bootstrap.scss, CSS-утилиты, кнопки, модальные окна, аккордеон и JS Bootstrap. Собственные стили страницы допустимы.

**Этап 2:** сохранить выборочную сборку, добавить аккордеон и только JS-плагин Collapse; перенести внешний вид из макета Pixso в SCSS-переменные. Точные цвета и размеры нужно взять из макета, а не выдать пример из методички за измерение.

Обязательная структура: app/index.html — исходный HTML; app/dist/styles.css и app/dist/bundle.js — результаты сборки. Webpack очищает только app/dist, не удаляет HTML. Нужны npm start, npm run build, package-lock.json, исходники, webpack-конфиг и workflow GitHub Pages. Для сдачи также требуется работающий Pages и Отчет.docx с авторством, процессом, командами, структурой и SCSS-переменными.

Проверить сетку на ширинах 375, 800, 1200: соответственно одна, две, три колонки. После первого этапа сохранить коммит demo-grid. Это особое требование задания: в собственном учебном проекте оно имеет приоритет над предпочтением пустых сообщений в общем каталоге методичек.

Экспериментальная группа использует SourceCraft Code Assistant, Context7 и на этапе макета Pixso Desktop/MCP. Нужно фиксировать реальные обращения к MCP, анализ плана, git diff и фактические проверки; недоступность инструмента отмечается честно. Журнал docs/ai-log.md и скриншоты включаются в отчёт. Методичка просит сначала запросить план, затем разрешать изменения небольшими этапами.
