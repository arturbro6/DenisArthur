# Пошаговый разбор

1. Открыть бесплатный аккаунт и явно зафиксировать тариф; платные возможности не выдавать за бесплатные.
2. Пройти весь список типов в конструкторе. Для доступных типов записать параметры и результат предпросмотра; для заблокированных отметить ограничение.
3. Проверить обязательность, несколько вариантов, длину ответа и экспорт на собственных тестовых данных.
4. Записать дату проверки и ограничения редактора. Не переносить устаревшие числовые лимиты из чужой статьи.
5. Составить таблицу тип → параметры → применение → ограничение бесплатного тарифа → подтверждение.
6. Сохранить одинаковые docx и pdf.

Проверка понимания: объясните каждое принятое решение; покажите собственный пример ошибки и способ её обнаружить. Итоговые скриншоты и результаты должны соответствовать реально выполненной работе.
