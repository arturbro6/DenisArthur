# Проект анкеты «Планирование учебных задач студентами»

Статус: содержание анкеты подготовлено; форма в Яндекс Формах ещё не создана, ссылка отсутствует. Это проект для индивидуального задания 2.2, а не готовый отчёт.

Цель — определить востребованные функции учебного планировщика перед разработкой ПО. Аудитория — студенты. Результаты помогут выбрать устройство, интерфейс и приоритеты функций; удобная выборка не является репрезентативной для всех студентов.

Вступление: «Здравствуйте! Приглашаем вас принять участие в опросе о планировании учебных задач. Он займёт около пяти минут. Участие добровольное; имя и контактные данные не требуются. Ответы будут использоваться в обобщённом виде для учебного проекта. Спасибо!»
