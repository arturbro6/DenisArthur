# Пошаговый разбор

1. Открыть редактор Яндекс Форм и его официальную справку. Создать черновую форму для проверки типов.
2. Для каждого доступного типа добавить один вопрос; выписать настройки обязательности, ограничений, вариантов и проверки ввода.
3. В предпросмотре отправить только собственные тестовые ответы: пустое значение, корректное и граничное. Не собирать реальные персональные данные ради теста.
4. Сопоставить вид вопроса и данные: один вариант — номинальная переменная; несколько вариантов — набор индикаторов; число — количественная переменная; шкала — порядковая; свободный текст требует кодирования.
5. Объяснить на примере своего опроса, зачем нужен каждый тип. Сверить полноту списка с текущим редактором.
6. Оформить docx и экспортировать pdf; проверить читаемость и одинаковое содержание.

Проверка понимания: объясните каждое принятое решение; покажите собственный пример ошибки и способ её обнаружить. Итоговые скриншоты и результаты должны соответствовать реально выполненной работе.
