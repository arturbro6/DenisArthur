# Дерево без сложных слов

Узел содержит значение и две ссылки на потомков. `None` означает отсутствие поддерева. Например, корень 2 с правилами x+1 и x−1 даёт потомков 3 и 1. К потомку 3 те же правила применяются заново: получаются 4 и 2.

```python
node = {"value": 2, "left": None, "right": None}
node["left"] = {"value": 3, "left": None, "right": None}
```

Словарь `{ключ: значение}` связывает названия с данными. `node["left"]` — весь словарь левого потомка, а не его число.

**Рекурсия** — функция вызывает саму себя на меньшей задаче. Нужны остановка и уменьшение задачи. Для дерева остановка — ноль оставшихся уровней, уменьшение — `height-1`. Без уменьшения получится бесконечная цепочка вызовов и `RecursionError`.

**Функция как аргумент:** `left_leaf` — не число, а правило. `left_leaf(root)` вызывает его. `lambda x: x*2` — краткая запись функции `def double(x): return x*2`. При передаче правила скобки не ставят: передают саму функцию, а не результат одного вызова.

`height: int` и `-> Tree` — аннотации, они помогают читателю и анализатору, но не выполняют автоматическую проверку данных. `Callable[[Number],Number]` читается как «функция, принимающая число и возвращающая число». `Any` в учебном типе словаря упрощает запись вложенной структуры.

`dict` удобен именованными полями. `tuple` компактнее, но позиции нужно помнить. `namedtuple` даёт именованные поля, но не позволяет просто присвоить потомка. Выбор контейнера опишите, а не перечисляйте названия.

При высоте h уровней узлов 2**h−1. Память самого дерева O(2**h); глубина стека рекурсии O(h). [Официальная документация функций](https://docs.python.org/3/tutorial/controlflow.html), [collections](https://docs.python.org/3/library/collections.html), [PEP 257](https://peps.python.org/pep-0257/).
