# Задача

Реализуйте `add(nums, target)`: получить список целых чисел и целую целевую сумму, вернуть индексы двух разных элементов, дающих эту сумму. Порядок индексов не важен. Один элемент нельзя брать дважды. В исходной ЛР указано, что решений нет либо оно одно.

Проверки из задания:

| nums | target | Подходящий результат |
|---|---:|---|
| `[2,7,11,15]` | 9 | `[0,1]` |
| `[3,2,4]` | 6 | `[1,2]` |
| `[3,3]` | 6 | `[0,1]` |

В дополнительном задании по тестам явно определён результат без пары — `None`; здесь используем тот же договор. Нужны код, тесты `unittest`, README с авторством и ссылка на репозиторий. Пример `add(a,b)` для Colab внизу страницы — демонстрация тестов, он не заменяет спецификацию `add(nums,target)`.

Источник задания: [ЛР 2 в Moodle](https://moodle.herzen.spb.ru/mod/assign/view.php?id=1294103).

Формулировка здесь изложена своими словами. При изменении требований преподавателем сверяйтесь со страницей Moodle и исходным файлом по ссылке.
