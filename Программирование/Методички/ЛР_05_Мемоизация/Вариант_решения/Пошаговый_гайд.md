# Пошаговый гайд с нуля

## Как выполнять шаги в своей папке

Сначала прочитайте [основы Python](../../Начать_здесь/README.md). В VS Code откройте именно `Вариант_решения` этой работы через File → Open Folder. Если скачали репозиторий ZIP, сначала распакуйте архив; внутри окна GitHub файлы не запускаются. Оригинальные примеры уже лежат здесь: перед редактированием сохраните их копию в другой учебной папке.

Для промежуточных упражнений создайте рядом `practice.py`; для запуска используйте терминал VS Code:

```bash
python3 practice.py
```

Каждый новый блок с указанием «замените» полностью заменяет содержимое `practice.py`. Не склеивайте все упражнения в один файл. После изменения сохраните файл, запустите и сравните результат с указанным. В терминале не должно быть `>>>`.

## Шаг 1. Запустить квадрат с памятью

Скопируйте первый пример теории в practice.py и выполните `python3 practice.py`. Ожидается:

```text
Вычисляем
9
Из памяти
9
```

Добавьте print(square(4)): это новый ключ, поэтому снова вычисление. Прежде чем работать с деревом, объясните, в какой строке сохраняется ответ и почему cache расположен снаружи.

## Шаг 2. Проверить декоратор на удвоении

Полностью замените practice.py:

```python
from memo import memoize

@memoize
def double(x):
    return x * 2

print(double(x=4))
print(double(x=4))
print(double.hits, double.misses)
double.cache_clear()
print(double.hits, double.misses)
```

Ожидается 8, 8, `1 1`, `0 0` на отдельных строках. @memoize относится только к следующему объявлению функции. Если счётчики непонятны, после каждого вызова печатайте их отдельно. После очистки повторный запрос снова будет промахом.

## Шаг 3. Сравнить все пять построителей

В папке уже есть baseline_recursive.py, baseline_iterative.py и memo.py. В memo.py строка `from ... import ... as ...` импортирует функцию под другим именем, чтобы не перепутать реализации. Не переименовывайте модули случайно: импорты зависят от имён файлов.

В practice.py введите:

```python
from memo import gen_bin_tree_recursive, gen_bin_tree_recursive_memo

left = lambda x: x + 1
right = lambda x: x - 1
ordinary = gen_bin_tree_recursive(3, 1, left, right)
cached = gen_bin_tree_recursive_memo(3, 1, left, right)
print(ordinary == cached)
print(cached["left"]["right"] is cached["right"]["left"])
print(ordinary["left"]["right"] is ordinary["right"]["left"])
```

Ожидается True, True, False. Два пути приводят к одному значению и одинаковой оставшейся высоте; кэш переиспользует узел. Объясните каждый результат до следующего шага.

## Шаг 4. Прочитать memo.py по таблице синтаксиса

Начните с memoize, затем recursive_memo, lru, iterative_memo. В рекурсивной версии следующие вызовы идут через мемоизированное имя, поэтому кэш применяется и внутри дерева. В итеративной найдите pop, флаг expanded, сохранение children и создание cache[key]. На маленьком дереве выпишите порядок извлечения троек. Не начинайте с benchmark.py: это отдельная программа измерений.

## Шаг 5. Запустить тесты

Введите `python3 -m unittest -v test_memo.py`. Ожидаются 8 тестов и OK. `setUp` выполняет очистку до каждого теста, `tearDown` — после. В test_shared_mutation намеренно меняют словарь: это демонстрация общего объекта, а не рекомендуемая операция над кэшем.

## Шаг 6. Сначала маленький замер

Команда вводится в терминал целиком:

```bash
python3 benchmark.py --variant 1 --max-height 4 --repeat 3
```

`benchmark.py` — файл программы; `--variant 1` выбирает вариант 1; `--max-height 4` ограничивает высоту; `--repeat 3` задаёт три повтора. Эти флаги разбирает argparse внутри программы, это не синтаксис выражений Python. Замените 1 номером своего варианта. Второй исследуемый вариант программа выбирает по условию автоматически.

Внутри Вариант_решения появится папка measurements с timings.csv и rule_calls.csv. Откройте CSV: первая строка содержит имена столбцов, следующие — результаты. Время зависит от компьютера; конкретное число секунд заранее не задаётся. Проверьте, что есть оба варианта и сценарии cold/warm для функций с постоянным кэшем.

## Шаг 7. Построить графики в отдельном окружении

В терминале Mac выполните по одной строке:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install matplotlib
python3 benchmark.py --variant 1 --max-height 4 --repeat 3 --plot
```

venv создаёт отдельную папку пакетов, source включает её в текущем терминале, pip устанавливает библиотеку именно этому Python, --plot включает построение PNG. На Windows окружение активируется командой `.venv\Scripts\Activate.ps1` в PowerShell; при блокировке активации можно вместо неё запускать `.venv\Scripts\python.exe -m pip install matplotlib` и `.venv\Scripts\python.exe benchmark.py ...`. Не меняйте системные настройки ради обхода ошибки: запишите её и используйте прямой путь к Python окружения. На Windows при первоначальном создании замените python3 на py.

Ожидается четыре PNG: два варианта × два сценария. Затем увеличивайте max-height постепенно, учитывая ограничение обычного построения в одну секунду. Программа исключает высоту, превысившую ограничение, из общего диапазона.

## Шаг 8. Составить выводы

Сравнивайте строки одной высоты и сценария. Ускорение = время обычной рекурсивной версии / время исследуемой. Объясните количество вызовов правил и эффект совпадения состояний, различие == и is, холодного и прогретого кэша. Приложите собственные CSV, PNG и проверенные параметры. Замедление при малом дереве — допустимый результат, его нужно объяснить стоимостью обслуживания кэша.

## Дополнительный разбор после первых запусков

# Выполняем исследование постепенно

## 1. Восстановите предыдущие реализации

В этой папке baseline_recursive.py и baseline_iterative.py содержат учебные версии предыдущих ЛР, поэтому своих прошлых файлов не требуется. Сначала запустите обе на высоте 3 и сравните результат. Задайте свой вариант через get_variant. Стандартные параметры в примерах относятся к варианту 1.

## 2. Проверьте декоратор на маленькой функции

Изучите memoize в memo.py отдельно от деревьев. Украсьте функцию удвоения числа; вызовите её два раза. Первый вызов должен увеличить misses, второй — hits. После cache_clear() оба счётчика равны нулю. Вызовите с именованным аргументом и убедитесь, что исключения нет.

## 3. Прочитайте каждую конструкцию

В wrapper сначала строится ключ; затем проверяется наличие в словаре; при попадании возвращается сохранённый результат, при промахе выполняется исходная функция и результат сохраняется. Исключение исходной функции не кэшируется. hash(key) в примере помогает явно обнаружить неподдерживаемые изменяемые аргументы.

## 4. Подключите кэш внутри рекурсии

Сравните gen_bin_tree_recursive_memo и обычную функцию: рекурсивные вызовы используют именно мемоизированное имя. Для правил x+1/x−1 проверьте tree['left']['right'] is tree['right']['left'] при высоте 3. Обычное дерево равное по содержимому, но эти узлы у него разные.

## 5. Разберите итеративный кэш

В стеке хранятся задания (высота, значение, готовы ли дети). При первом извлечении родитель откладывается с флагом True, затем добавляются дети. При втором извлечении он собирается из кэша готовых детей. Высота уменьшается, поэтому циклической зависимости нет. Ключ хранит (height, value), а правила постоянны в пределах одного вызова.

## 6. Проверьте последствия изменения

Запустите test_memo.py командой `python3 -m unittest -v`. Тест shared_mutation специально меняет общий узел и показывает изменение другой ветви и следующего вызова. После теста кэш очищается. Это демонстрация свойства памяти, а не рекомендуемое использование кэшированных словарей.

## 7. Снимите собственные времена

`python3 benchmark.py --variant 1 --max-height 12 --repeat 3`

Замените 1 на свой вариант. Скрипт создаст timings.csv и rule_calls.csv. Для каждого холодного измерения очистка происходит до включения таймера. Для прогретого сценария — один пробный вызов перед таймером. Все функции исследуются на одинаковых высотах. Если базовое построение превысило секунду, эта высота исключается для обоих вариантов, диапазон заканчивается. Скрипт не выдаёт заранее придуманных ускорений.

## 8. Постройте графики

Установите matplotlib в своём виртуальном окружении: `python3 -m pip install matplotlib`. Затем `python3 benchmark.py --variant НОМЕР --max-height 12 --repeat 3 --plot`. Получатся отдельные PNG для каждого варианта и сценария. Разберите CSV и подписи осей, объясните, почему в прогретом сценарии меньше кривых.

## 9. Сформулируйте выводы по своим данным

В каждой строке сравнения ускорение = время обычной рекурсивной / время исследуемой. Не объединяйте разные высоты в один коэффициент. По rule_calls.csv сравните обращения к left/right: варианты с повторяющимися состояниями дают больше пользы. Если обнаружено замедление, объясните цену ключей и словаря, а не удаляйте неудобный результат.

## Самостоятельный шаг

Передавайте каждый раз новую lambda с тем же выражением. Сначала предскажите, будут ли попадания между вызовами, затем проверьте cache_info или hits. Объекты функций новые, поэтому ключи различаются. Второе упражнение — закэшировать только внешний вызов обычной рекурсии и сравнить первый и второй запуск.

Для отчёта приложите ваши варианты, конвенцию высоты, диапазон, повторы, таблицы, графики и ответы на все вопросы в условии. В учебном файле используются хешируемые числовые значения; универсальное кэширование любых Python-объектов этой задачей не требуется.
