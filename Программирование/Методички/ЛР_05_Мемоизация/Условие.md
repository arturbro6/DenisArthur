# Задача по странице Moodle

На основе ЛР 3 и 4 сравните пять реализаций:

1. Рекурсивную без кэша.
2. Итеративную без кэша.
3. Рекурсивную с собственным декоратором memoize; внутренние вызовы должны проходить через кэш.
4. Итеративную с внутренним кэшем поддеревьев по паре (высота, значение корня).
5. Рекурсивную с functools.lru_cache и выводом cache_info().

Собственный декоратор должен учитывать позиционные и именованные аргументы, использовать functools.wraps, предоставлять cache_clear() и счётчики попаданий/промахов. Все версии возвращают равные деревья.

Измерьте timeit на своём варианте и варианте 13; если свой — 13, вторым возьмите 9. Для всех функций используйте один диапазон высот и несколько повторов. Верхнюю высоту подберите так, чтобы одно построение без кэша занимало не более секунды. Это проверяется на вашем компьютере, а не берётся из чужого отчёта.

Разделите сценарии: одно построение с очисткой кэша перед замером; повторный вызов с теми же аргументами только для реализаций с постоянным кэшем. Посчитайте обращения к правилам потомков или разные состояния поддеревьев. Постройте matplotlib-графики (X — высота, Y — время), по отдельности для двух вариантов и сценариев.

Тестами проверьте равенство деревьев с обычными и пользовательскими параметрами; фактическое повторное использование результатов декоратором; общие объекты через is и распространение мутаций. В README нужны таблицы, графики и объяснение ускорений, замедлений на малой высоте, разницы внешней обёртки и декоратора рекурсивного определения, lru_cache и новых lambda между вызовами.

Параметры вариантов — [как в ЛР 3](../ЛР_03_Дерево_Рекурсия/Условие.md). В этой папке они также находятся в variants.py.

Источник задания: [ЛР 5 в Moodle](https://moodle.herzen.spb.ru/mod/assign/view.php?id=1373443).

Формулировка здесь изложена своими словами. При изменении требований преподавателем сверяйтесь со страницей Moodle и исходным файлом по ссылке.
