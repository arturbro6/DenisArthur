# От первого print к своей функции

Сначала прочитайте [основы Python](../../Начать_здесь/README.md). Эта часть объясняет синтаксис до применения в лабораторной.

## Разбираем hello.py по частям

```python
def greet(name: str) -> str:
    """Вернуть приветствие, не печатая его."""
    return "Привет, " + name
```

`greet` означает «приветствовать», но это обычное имя, не специальная команда. `name: str` — входной текст. `-> str` — подсказка, что возвращается текст. Тройные кавычки — строка документации о назначении функции; она не печатается. `return` соединяет две строки. В учебном файле ниже есть:

```python
if __name__ == "__main__":
    print(greet("Артур"))
```

Здесь два символа подчёркивания с каждой стороны специальных имён. Python сам задаёт `__name__`: при прямом запуске файла это `"__main__"`. Поэтому при запуске hello.py приветствие печатается, а при импорте функции в тест — нет. Внутренний вызов `greet` сначала возвращает текст; внешний `print` затем показывает его.

`from hello import greet` в другом файле читается «из файла hello.py взять функцию greet». Расширение `.py` в импорте не пишется. Оба файла должны лежать рядом.

# Что нужно понять перед первым запуском

**Код** — текст инструкций. **Интерпретатор Python** выполняет эти инструкции. **VS Code** — редактор; сам по себе он не заменяет Python. **Терминал** запускает команды. **Рабочая папка** — каталог, относительно которого ищутся файлы.

```python
name = "Артур"
print("Привет,", name)
```

`name` — имя переменной, `=` сохраняет значение, кавычки обозначают строку. `print(...)` вызывает функцию вывода. Отступы в Python определяют вложенные блоки: четыре пробела внутри функции — часть синтаксиса.

```python
def greet(name):
    return "Привет, " + name
```

`def` объявляет функцию; `name` внутри скобок — параметр; `return` отдаёт результат вызывающему коду. Функция ничего не печатает сама. Это удобно для тестирования.

**Модуль** — один файл `.py`. `from hello import greet` берёт функцию из `hello.py`, лежащего рядом. `.venv` хранит отдельное окружение проекта; в Git его не добавляют.

Официальная основа: [введение Python](https://docs.python.org/3/tutorial/introduction.html), [venv](https://docs.python.org/3/library/venv.html). Книга Moodle содержит отдельную главу macOS; на вашем Mac используйте `python3`, на Windows обычно `py`.
