# Пошаговый гайд с нуля

## Как выполнять шаги в своей папке

Сначала прочитайте [основы Python](../../Начать_здесь/README.md). В VS Code откройте именно `Вариант_решения` этой работы через File → Open Folder. Если скачали репозиторий ZIP, сначала распакуйте архив; внутри окна GitHub файлы не запускаются. Оригинальные примеры уже лежат здесь: перед редактированием сохраните их копию в другой учебной папке.

Для промежуточных упражнений создайте рядом `practice.py`; для запуска используйте терминал VS Code:

```bash
python3 practice.py
```

Каждый новый блок с указанием «замените» полностью заменяет содержимое `practice.py`. Не склеивайте все упражнения в один файл. После изменения сохраните файл, запустите и сравните результат с указанным. В терминале не должно быть `>>>`.

## Шаг 1. Проверить Python

В терминале введите `python3 --version`. Должна появиться версия Python 3. Примеры следующих работ используют подсказки типов Python 3.10 или новее. Если Python не найден, выполните инструкцию установки из условия ЛР №1; VS Code сам его не устанавливает.

## Шаг 2. Ввести простую функцию

В новый `practice.py` введите:

```python
def greet(name):
    return "Привет, " + name

print(greet("Артур"))
```

Запустите `python3 practice.py`. Ожидается `Привет, Артур`. Замените Артур на Сергей, предскажите и проверьте результат. Уберите последнюю строку: вывода не будет, потому что функция только объявлена.

## Шаг 3. Прочитать полный файл

Откройте hello.py. Сопоставьте его с упражнением: аннотации добавляют подсказки, документация объясняет назначение, блок `__main__` управляет прямым запуском. Запустите `python3 hello.py`; ожидается то же приветствие.

## Шаг 4. Запустить готовый тест

В том же терминале выполните `python3 -m unittest -v`. `-m` запускает модуль Python, `unittest` — встроенную систему тестов, `-v` показывает имена проверок. В конце ожидаются `Ran 1 test` и `OK`. Это означает, что проверка прошла. Ничего устанавливать через pip для unittest не требуется.

## Шаг 5. Проверить понимание

Измените только текст приветствия в hello.py и запустите тест повторно. Если ожидание теста осталось прежним, он обнаружит изменение. Верните согласованный результат. В отчёте ЛР №1 выполняйте требования о среде из условия: hello.py — тренировочное упражнение.

## Дополнительный разбор после первых запусков

# Шаг за шагом

## 1. Проверьте Python

Откройте терминал VS Code: Terminal → New Terminal. На Mac выполните `python3 --version`, на Windows — `py --version`. Если версия уже выводится, повторно устанавливать Python не нужно. Если команды нет, установите Python 3 с [python.org](https://www.python.org/downloads/), как описано в книге Moodle. На Windows обратите внимание на PATH; на Mac выберите установщик для macOS.

## 2. Откройте именно папку

Создайте собственную рабочую папку, выберите File → Open Folder. Создайте `hello.py`. Проверьте `pwd` на Mac или `Get-Location` в PowerShell: терминал должен находиться в папке с файлом.

## 3. Напишите маленькую функцию

Напишите `greet(name)` из теории. Ниже добавьте вызов `print(greet("Артур"))`. Сначала предскажите вывод, затем запустите `python3 hello.py` (Windows: `py hello.py`). Поменяйте имя и проверьте, что изменилось.

## 4. Отделите запуск от импорта

Посмотрите `hello.py` в этой папке. Условие `if __name__ == "__main__":` означает: выполнять этот блок только при прямом запуске файла. При импорте в тесты приветствие не печатается.

## 5. Запустите первый тест

Откройте `test_hello.py`. `assertEqual` сравнивает полученный результат с ожидаемым. Запустите из этой папки `python3 -m unittest -v`. Сначала временно измените ожидаемое приветствие и увидьте падение; затем верните правильное значение. Так становится понятно, что тест действительно что-то проверяет.

## 6. Подготовьте Git

В собственном проекте выполните `git init`, затем создайте `.gitignore` с `.venv/`, `__pycache__/` и `.DS_Store`. Выполните `git status` и убедитесь, что служебные файлы не попали в список. Авторство укажите в README. Сообщения коммитов для этого общего репозитория оставляем пустыми; для собственного проекта следуйте требованиям преподавателя.

## Самостоятельный шаг

Добавьте функцию, которая возвращает приветствие с восклицательным знаком, и отдельный тест. Объясните разницу между `return` и `print` без запуска.

## Если не работает

`can't open file` — неверная папка или имя файла. `ModuleNotFoundError: hello` — тест находится не рядом с модулем или запущен из другой папки. `IndentationError` — проверьте пробелы, не смешивайте табы и пробелы.

Готовность: можете создать файл, выполнить его, запустить тест, показать `git status` и объяснить каждую строку примера.
