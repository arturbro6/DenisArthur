# Python с нуля: куда писать и как читать код

## Сначала различите три места ввода

| Место | Что туда вводить | Пример |
|---|---|---|
| Файл в редакторе VS Code | Код Python; сохраняется с расширением `.py` | `print(2 + 3)` |
| Терминал VS Code (меню Terminal → New Terminal / Терминал → Новый терминал) | Команду запуска файла | `python3 hello.py` |
| Окно вывода | Здесь читают результат; вводить его обратно не нужно | `5` |

В этой методичке блок `python` означает код для файла, блок `bash` — команду терминала, блок `text` — ожидаемый вывод. Названия блоков, строки с тройными обратными кавычками и номера шагов не копируйте в файл. Команду `python3 ...` не пишите внутри `.py`.

На Mac используется `python3`. На Windows сначала проверьте `py --version`; если работает, в командах запуска заменяйте `python3` на `py`. В терминале команда выполняется после Enter. Сам код вводится латинскими буквами, русским может быть текст в кавычках и комментарий.

## Простейшая программа — выполнить до лабораторной

Откройте VS Code → File → Open Folder (Файл → Открыть папку). Создайте отдельную учебную папку, например `python_practice`. В панели Explorer / Проводник нажмите New File / Новый файл, введите `first.py`. Вставьте:

```python
name = "Артур"
age = 21
print("Привет,", name)
print(age + 1)
```

Сохраните Cmd+S на Mac / Ctrl+S на Windows. Откройте терминал в этой папке и выполните:

```bash
python3 first.py
```

Ожидаемый вывод:

```text
Привет, Артур
22
```

`name` и `age` — придуманные нами имена переменных, они хранят значения. `=` означает «сохранить справа в имя слева». Кавычки ограничивают строку (текст). Число пишется без кавычек. `print(...)` выводит содержимое скобок; запятая разделяет несколько аргументов. `+` складывает числа, а для двух строк соединяет текст. `print` и `Print` — разные имена: регистр важен.

Если терминал показывает приглашение `>>>`, вы открыли интерактивный Python. Введите `exit()` и нажмите Enter, затем выполняйте команды запуска. Символы `>>>` из чужих примеров копировать не нужно.

## Словарь знаков, встречающихся в работах

| Запись | Читаем словами | Пример |
|---|---|---|
| `# текст` | Комментарий до конца строки | `# считаем сумму` |
| `=` / `==` | Присвоить / сравнить | `x = 2`, `x == 2` |
| `!=`, `<`, `<=`, `>` | Не равно, меньше, не больше, больше | `i != j` |
| `+`, `-`, `*`, `/` | Сложение, вычитание, умножение, деление | `6 / 2` даёт `3.0` |
| `**` / `%` | Степень / остаток деления | `2 ** 3` → 8; `7 % 3` → 1 |
| `(...)` | Вызов функции, группировка или кортеж — зависит от контекста | `print(2)`; `(2, 3)` |
| `[...]` | Список или обращение к элементу | `[4, 9]`; `nums[0]` → 4 |
| `{...}` | Словарь ключей и значений | `{"value": 2}` |
| `:` после условия/def/цикла | Начало вложенного блока | После строки нажать Enter и сделать отступ |
| `:` внутри словаря | Отделяет ключ от значения | `"left": None` |
| `True`, `False` | Истина, ложь; с большой буквы | Результат сравнения |
| `None` | Значения нет; не строка `"None"` | Функция не нашла пару |
| `in`, `not`, `and`, `or` | Содержится; отрицание; и; или | `3 in [2, 3]` → True |

В Python `^` не возводит в степень: это побитовая операция. Десятичная дробь записывается с точкой: `1.5`. Кавычки должны быть обычными `'` или `"`, а не типографскими «ёлочками».

## Отступы — часть программы

```python
x = 3
if x > 0:
    print("Положительное")
print("Проверка закончена")
```

`if` означает «если». Строка с четырьмя пробелами выполняется только при истинном условии. Последняя строка без отступа выполняется после проверки в любом случае. Используйте четыре пробела на уровень; вложенный блок — восемь. Не смешивайте Tab и пробелы. После `:` редактор обычно делает отступ сам. Пустые строки служат читаемости.

## Функция: объявить — не значит выполнить

```python
def add_one(number):
    return number + 1

answer = add_one(4)
print(answer)
```

`def` создаёт функцию; `add_one` — её имя; `number` — параметр (входное значение). Двоеточие открывает тело с отступом. `return` отдаёт результат и сразу завершает вызов. `add_one(4)` запускает функцию со значением 4. В `answer` сохраняется 5, `print` его показывает. Если оставить только объявление `def`, вывода не будет — это нормально.

`def f(x=1)` задаёт значение по умолчанию: `f()` использует 1, `f(5)` использует 5. Вызов `f(x=5)` явно называет параметр. `def f(x: int) -> int` содержит подсказки типов: `int` — целое число, `str` — строка, `float` — число с дробной частью. Подсказки не преобразуют данные автоматически.

## Ошибка — это подсказка о месте проблемы

| Сообщение | Что проверить первым |
|---|---|
| `SyntaxError` | Двоеточие, скобки, кавычки и строку перед указанной |
| `IndentationError` | Отступы тела функции/цикла/условия |
| `NameError` | Опечатку имени и строку, где значение должно было создаться |
| `TypeError` | Не пытаетесь ли складывать число со строкой или вызывать число как функцию |
| `ModuleNotFoundError` | Файл импорта рядом? Терминал в нужной папке? |
| `can't open file` | Имя файла, расширение и текущую папку |
| `command not found` | Установлен ли Python и правильная ли команда запуска |

Читайте последнюю строку ошибки, затем имя вашего файла и номер строки над ней. Номера строк в редакторе помогают найти место; в сам код номера не добавляют.

Перед переходом дальше измените имя и возраст в `first.py`, предскажите вывод, сохраните и проверьте. Затем объясните разницу между `return` и `print` без подсказки.
