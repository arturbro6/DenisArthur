# Словари, функции-правила и рекурсия

Сначала прочитайте [основы Python](../../Начать_здесь/README.md). Эта часть объясняет синтаксис до применения в лабораторной.

## Один узел — обычный словарь

```python
node = {"value": 2, "left": None, "right": None}
print(node["value"])
node["left"] = {"value": 3, "left": None, "right": None}
print(node["left"]["value"])
```

Вывод 2 и 3. `value`, `left`, `right` — текстовые ключи. `node["left"]` даёт целый словарь потомка; ещё одни квадратные скобки берут его значение. Запись слева от `=` меняет поле. Словарь хранит ссылки на потомков, поэтому возникает дерево. Пока потомка нет, поле равно None.

## Передаём правило, а не готовое число

```python
def double(x):
    return x * 2

rule = double
print(rule(3))
```

Вывод 6. `rule = double` сохраняет саму функцию; `rule(3)` её вызывает. Скобки важны: `rule = double(3)` сохранило бы число 6, которое вызвать нельзя. `lambda x: x * 2` — короткая функция с одним выражением, эквивалентная double. Внутри lambda двоеточие отделяет параметр от выражения; return не пишется.

## Самовызов по маленьким шагам

Рекурсия — вызов той же функции из её тела. Для дерева аргумент height означает оставшееся число уровней. При 0 возвращаем None. При 1 создаём только узел. При большем числе создаём узел и просим ту же функцию построить его левую и правую части с height−1. Высота уменьшается, поэтому вызовы останавливаются. Сначала полностью вычисляется результат вызова справа от `=`, затем он записывается в поле потомка.

При height=2, root=1 и правилах +1/−1: создаётся корень 1; вызов для левого потомка получает (1, 2), создаёт лист 2 и возвращает словарь; правый вызов получает (1, 0) и возвращает лист 0; внешний вызов возвращает весь корень. Значение узла 0 не означает отсутствия узла: отсутствие обозначено None.

## Читать оформление полного tree.py

`from typing import Callable, Any` подключает обозначения типов для подсказок. `Number = int | float` называет тип «целое или дробное». `Tree = dict[str, Any] | None` описывает результат. `Callable[[Number], Number]` — правило, которое принимает одно число и возвращает число. При первом чтении мысленно оставьте только имена параметров: height, root, left_leaf, right_leaf.

`isinstance(height, int)` проверяет тип. `not` отрицает проверку, `or` объединяет альтернативы ошибки. `bool` проверяется отдельно: True в Python связан с целым типом, а высотой быть не должен. `raise ValueError("...")` прекращает выполнение с понятным сообщением при неверной высоте. Это отличается от return None для корректного пустого дерева.

В variants.py лежат готовые правила вариантов. `get_variant(number)` возвращает четыре значения: корень, высоту, левое правило, правое правило. Присваивание `root, height, left, right = ...` раскладывает их в четыре имени. Номер варианта берётся по условию, не из имени участника.

## Дополнительный разбор после первых запусков

# Дерево без сложных слов

Узел содержит значение и две ссылки на потомков. `None` означает отсутствие поддерева. Например, корень 2 с правилами x+1 и x−1 даёт потомков 3 и 1. К потомку 3 те же правила применяются заново: получаются 4 и 2.

```python
node = {"value": 2, "left": None, "right": None}
node["left"] = {"value": 3, "left": None, "right": None}
```

Словарь `{ключ: значение}` связывает названия с данными. `node["left"]` — весь словарь левого потомка, а не его число.

**Рекурсия** — функция вызывает саму себя на меньшей задаче. Нужны остановка и уменьшение задачи. Для дерева остановка — ноль оставшихся уровней, уменьшение — `height-1`. Без уменьшения получится бесконечная цепочка вызовов и `RecursionError`.

**Функция как аргумент:** `left_leaf` — не число, а правило. `left_leaf(root)` вызывает его. `lambda x: x*2` — краткая запись функции `def double(x): return x*2`. При передаче правила скобки не ставят: передают саму функцию, а не результат одного вызова.

`height: int` и `-> Tree` — аннотации, они помогают читателю и анализатору, но не выполняют автоматическую проверку данных. `Callable[[Number],Number]` читается как «функция, принимающая число и возвращающая число». `Any` в учебном типе словаря упрощает запись вложенной структуры.

`dict` удобен именованными полями. `tuple` компактнее, но позиции нужно помнить. `namedtuple` даёт именованные поля, но не позволяет просто присвоить потомка. Выбор контейнера опишите, а не перечисляйте названия.

При высоте h уровней узлов 2**h−1. Память самого дерева O(2**h); глубина стека рекурсии O(h). [Официальная документация функций](https://docs.python.org/3/tutorial/controlflow.html), [collections](https://docs.python.org/3/library/collections.html), [PEP 257](https://peps.python.org/pep-0257/).
