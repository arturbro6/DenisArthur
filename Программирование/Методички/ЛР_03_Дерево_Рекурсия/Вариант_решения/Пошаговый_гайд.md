# Пошаговый гайд с нуля

## Как выполнять шаги в своей папке

Сначала прочитайте [основы Python](../../Начать_здесь/README.md). В VS Code откройте именно `Вариант_решения` этой работы через File → Open Folder. Если скачали репозиторий ZIP, сначала распакуйте архив; внутри окна GitHub файлы не запускаются. Оригинальные примеры уже лежат здесь: перед редактированием сохраните их копию в другой учебной папке.

Для промежуточных упражнений создайте рядом `practice.py`; для запуска используйте терминал VS Code:

```bash
python3 practice.py
```

Каждый новый блок с указанием «замените» полностью заменяет содержимое `practice.py`. Не склеивайте все упражнения в один файл. После изменения сохраните файл, запустите и сравните результат с указанным. В терминале не должно быть `>>>`.

## Шаг 1. Освоить узел

Введите в practice.py пример со словарём из теории и запустите. Получите 2 и 3. Измените только значение левого потомка на 8: вторым должно напечататься 8. Объясните, почему нужны две пары квадратных скобок.

## Шаг 2. Набрать простую рекурсивную функцию

Полностью замените practice.py:

```python
def build(height, value):
    if height == 0:
        return None
    node = {"value": value, "left": None, "right": None}
    if height > 1:
        node["left"] = build(height - 1, value + 1)
        node["right"] = build(height - 1, value - 1)
    return node

print(build(0, 1))
print(build(1, 1))
print(build(2, 1))
```

Запустите `python3 practice.py`. Вывод:

```text
None
{'value': 1, 'left': None, 'right': None}
{'value': 1, 'left': {'value': 2, 'left': None, 'right': None}, 'right': {'value': 0, 'left': None, 'right': None}}
```

Одинарные кавычки в выводе допустимы: Python так показывает строки словаря. Код выше использует только два уровня вложенных отступов. Не увеличивайте высоту, пока не можете вручную объяснить три строки вывода.

## Шаг 3. Подключить изменяемые правила

Прочитайте полный tree.py рядом. Там вместо жёстких +1/−1 вызываются функции left_leaf и right_leaf. В practice.py полностью замените код:

```python
from tree import gen_bin_tree

def left(x):
    return x + 1

def right(x):
    return x - 1

result = gen_bin_tree(2, 1, left, right)
print(result["left"]["value"])
print(result["right"]["value"])
```

Ожидается 2 и 0. Передаём `left`, а не `left()`: входное число правилу даст построитель. После этого замените правила короткими lambda и убедитесь, что результат не меняется.

## Шаг 4. Выбрать вариант

Замените practice.py:

```python
from tree import gen_bin_tree
from variants import get_variant

root, height, left, right = get_variant(1)
tree = gen_bin_tree(height, root, left, right)
print(root, height)
print(tree["left"]["value"], tree["right"]["value"])
```

Для варианта 1 ожидаются `1 5` и `2 4`. Замените 1 своим номером и сверяйте корень/высоту/правила с таблицей условия. В методичке высота — число уровней; согласуйте другое соглашение с преподавателем, если оно требуется.

## Шаг 5. Проверить

Выполните `python3 -m unittest -v test_tree.py`. Ожидается 8 тестов и OK. Затем изучите тесты отдельно: assertEqual сравнивает содержимое, assertIsNot проверяет, что равные поддеревья остаются разными объектами. В отчёте объясните остановку, уменьшение height, выбор словаря и различие правил. Самостоятельно предскажите четыре значения третьего уровня для правил +1/−1.

## Дополнительный разбор после первых запусков

# Строим дерево по частям

## 1. Выберите вариант и договор о высоте

Откройте таблицу в условии. В `variants.py` функции уже переведены в Python. Например, `root,height,left,right = get_variant(номер)`; затем `gen_bin_tree(height,root,left,right)`. Пока тренируетесь, используйте маленькую высоту 2 или 3. В примере высота означает число уровней.

## 2. Постройте один узел руками

Напишите словарь с `value`, `left`, `right`. Для height=1 потомки равны None. Проверка одного уровня должна проходить до добавления рекурсии.

## 3. Добавьте остановку

Если height=0, верните None. Если высота отрицательна или дробная, учебный вариант выдаёт ValueError. Это явно выбранное поведение для некорректного входа; исходное задание его не определяет.

## 4. Добавьте левое поддерево

Вызовите ту же функцию с height−1 и новым корнем `left_leaf(root)`. Передайте оба правила дальше. Если не передать пользовательские правила в следующий вызов, на глубине начнут использоваться стандартные — это частая ошибка.

## 5. Аналогично добавьте правое

Сначала решите на бумаге: root=1, h=3, левое x+1, правое x−1. По уровням должны быть 1; затем 2,0; затем 3,1,1,−1. Совпадающие значения здесь находятся в разных узлах. Сравните бумагу с `pprint(tree)`.

## 6. Пройдите тесты

Напишите тесты нулевой высоты, одного корня, двух уровней, пользовательских правил и нулевого корня. Затем `python3 -m unittest -v`. В приложенном файле дополнительно проверены все 18 вариантов на первых потомках.

## 7. Исследуйте контейнер

Постройте маленький узел как `namedtuple("Node", "value left right")` из collections. Сравните чтение `node.value` и `node["value"]`, возможность изменения и удобство вывода. Не нужно переписывать всё дерево ради галочки: опишите обоснованный вывод на конкретном примере.

## Самостоятельный шаг

Измените оба правила на умножение и посчитайте третий уровень вручную. Добавьте тест, который поймает применение правил к первоначальному корню вместо текущего. Объясните, где рекурсия возвращается к правой ветви после завершения левой.

Перед сдачей: замените параметры по умолчанию на свой вариант, укажите авторство, конвенцию высоты, команды запуска и результаты тестов. `tree.py` — пример, с которым сравнивается ваш вариант, а не основание утверждать, что ваш номер в группе равен 1.
