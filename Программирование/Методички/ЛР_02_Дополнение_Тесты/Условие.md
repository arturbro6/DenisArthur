# Задача

Напишите не менее восьми разных тестов для `add(nums,target)` в отдельном `test_add.py`, рядом с `add.py`. Допускается любая подходящая пара разных индексов; при отсутствии решения требуется `None`. Если пар несколько, принимается любая из них.

В README объясните группы входов, возможную ошибку, которую ловит каждый тест, и разнообразие набора. Оцениваются тесты, а не реализация `add`. Это дополнение опубликовано 17.11.2026; на просмотренной странице срок указан 23.11.2026, 23:59.

Для сдачи дополняется репозиторий «Сумма двух» файлами `test_add.py` и README.

Источник задания: [дополнение в Moodle](https://moodle.herzen.spb.ru/mod/assign/view.php?id=1379123).

Формулировка здесь изложена своими словами. При изменении требований преподавателем сверяйтесь со страницей Moodle и исходным файлом по ссылке.
