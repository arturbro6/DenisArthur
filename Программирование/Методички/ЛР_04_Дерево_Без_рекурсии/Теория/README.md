# Очередь вместо самовызова

Сначала прочитайте [основы Python](../../Начать_здесь/README.md). Эта часть объясняет синтаксис до применения в лабораторной.

## Сначала освоим очередь без дерева

```python
from collections import deque
queue = deque(["первый", "второй"])
queue.append("третий")
while queue:
    item = queue.popleft()
    print(item)
```

Вывод: первый, второй, третий на отдельных строках. `collections` — встроенный модуль; `deque` — готовый тип очереди. `append` кладёт элемент в конец, `popleft` берёт и удаляет первый. Точка в `queue.append(...)` означает «вызвать метод этого объекта». `while` повторяет тело, пока условие истинно. Непустая очередь считается истиной, пустая — ложью. Без удаления элемента цикл не закончился бы.

## Пара из узла и уровня

`(node, 1)` — кортеж из двух элементов: самого словаря узла и номера уровня. Список из одной такой пары — `[(node, 1)]`. Вызов `deque([(node, 1)])` создаёт очередь с одним заданием. `node, level = queue.popleft()` достаёт пару и раскладывает её по именам.

Когда `level == height`, у узла больше не должно быть потомков. `continue` пропускает оставшиеся строки текущего прохода while и переходит к следующему извлечению; это не return и не завершение всей функции. Иначе вычисляем два значения, создаём два словаря, присоединяем их к родителю и добавляем новые задания с `level + 1`.

## Почему меняется общее дерево

`alias = tree` не копирует словарь: оба имени указывают на один объект. Поэтому изменение `alias["left"]` видно при чтении tree. Очередь хранит именно ссылки на существующие узлы, и мы достраиваем их на месте. Если записывать в очередь одни числа, будет потеряно указание, к какому родителю присоединять детей.

В полном tree.py аннотации и проверка высоты те же, что в рекурсивной работе. Импорт deque добавлен для очереди. Снаружи функция всё так же принимает высоту, корень и два правила; пользователь функции может не знать, какой способ построения внутри. `return tree` стоит после while: возвращаем только достроенное дерево.

## Дополнительный разбор после первых запусков

# Чем заменить рекурсивные вызовы

Нужно хранить ещё не обработанные узлы самостоятельно. **Стек** работает «последним положили — первым взяли»; **очередь** — «первым положили — первым взяли». В приложенном варианте выбрана очередь и построение по уровням.

```python
from collections import deque
queue = deque([(tree, 1)])
node, level = queue.popleft()
```

`deque` — двусторонняя очередь. Внутри лежит кортеж `(ссылка на узел, номер уровня)`. Запись `node, level = ...` распаковывает пару. `popleft()` удаляет первый элемент. `append(...)` добавляет в конец. В отличие от `list.pop(0)`, извлечение начала не требует сдвигать весь список.

```python
while queue:
    ...
```

Пустая очередь считается ложью, цикл завершается. `continue` пропускает оставшуюся часть одной итерации, не завершает всю функцию. У последнего уровня нет потомков.

В очередь кладутся ссылки на существующие словари. Изменение `node["left"]` становится видно в общем дереве: это тот же объект. Если вместо ссылки хранить только число, присоединить потомков к нужному родителю будет сложнее.

BFS — обработка по уровням; DFS — проход одной ветви до конца. Оба подхода могут строить одинаковое дерево. Здесь очередь в максимуме хранит O(2**h) узлов, само дерево тоже O(2**h). Итеративный вариант со стеком может уменьшить дополнительное хранение заданий, но не размер готового дерева.

[Документация deque](https://docs.python.org/3/library/collections.html#collections.deque).
