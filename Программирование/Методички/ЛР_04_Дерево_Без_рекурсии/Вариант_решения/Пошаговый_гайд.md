# Пошаговый гайд с нуля

## Как выполнять шаги в своей папке

Сначала прочитайте [основы Python](../../Начать_здесь/README.md). В VS Code откройте именно `Вариант_решения` этой работы через File → Open Folder. Если скачали репозиторий ZIP, сначала распакуйте архив; внутри окна GitHub файлы не запускаются. Оригинальные примеры уже лежат здесь: перед редактированием сохраните их копию в другой учебной папке.

Для промежуточных упражнений создайте рядом `practice.py`; для запуска используйте терминал VS Code:

```bash
python3 practice.py
```

Каждый новый блок с указанием «замените» полностью заменяет содержимое `practice.py`. Не склеивайте все упражнения в один файл. После изменения сохраните файл, запустите и сравните результат с указанным. В терминале не должно быть `>>>`.

## Шаг 1. Проверить очередь

Введите пример с тремя словами из теории в practice.py. Запустите `python3 practice.py`, получите слова в исходном порядке. Поменяйте append на другое слово и предскажите порядок. Этот шаг нужен, чтобы понимать очередь до сложного дерева.

## Шаг 2. Набрать построитель без рекурсии

Полностью замените practice.py:

```python
from collections import deque

def build(height, value):
    if height == 0:
        return None
    tree = {"value": value, "left": None, "right": None}
    queue = deque([(tree, 1)])
    while queue:
        node, level = queue.popleft()
        if level == height:
            continue
        node["left"] = {"value": node["value"] + 1, "left": None, "right": None}
        node["right"] = {"value": node["value"] - 1, "left": None, "right": None}
        queue.append((node["left"], level + 1))
        queue.append((node["right"], level + 1))
    return tree

result = build(2, 1)
print(result["left"]["value"])
print(result["right"]["value"])
```

Ожидается 2 и 0. В этом учебном фрагменте передаём только неотрицательную целую высоту; полная проверка входа есть в tree.py. Найдите имя build: оно встречается в объявлении и в строке запуска, но не вызывается в собственном теле. Значит, рекурсии здесь нет.

## Шаг 3. Проследить очередь вручную

До while там одна пара: корень/уровень 1. После обработки корня — две пары: левый узел/2, правый узел/2. Оба на последнем уровне; каждый удалится без новых заданий. После этого очередь пуста и возвращается tree. Для высоты 3 перед запуском выпишите, какие задания добавятся после левого узла.

## Шаг 4. Перейти к полному варианту

Откройте tree.py. Его left_value и right_value вычисляются переданными правилами вместо жёстких +1/−1. В practice.py введите:

```python
from tree import gen_bin_tree
from variants import get_variant
root, height, left, right = get_variant(1)
tree = gen_bin_tree(height, root, left, right)
print(tree["value"])
print(tree["left"]["value"], tree["right"]["value"])
```

Ожидается 1, затем `2 4`. Замените номер своим. Запустите `python3 -m unittest -v test_tree.py`: ожидаются 8 тестов и OK.

## Шаг 5. Объяснить различие

Сравните результат с рекурсивной работой на маленькой высоте. Содержимое одинаковое, способ хранения ещё не выполненных задач разный. В отчёте покажите очередь на каждом проходе для высоты 2 и объясните continue, append, popleft и return после цикла.

## Дополнительный разбор после первых запусков

# Построение с очередью

## 1. Не начинайте с полного дерева

Перенесите только создание корня и обработку height=0. Функция не должна вызывать сама себя ни прямо, ни через помощника. Вызов библиотечной очереди рекурсией не является.

## 2. Создайте очередь

Добавьте `(tree,1)`. Пока распечатайте значение извлечённого узла и его уровень. Убедитесь, что извлекается исходный словарь корня.

## 3. Определите, когда не нужны дети

Если level равен height, выполните continue. Для height=1 корень остаётся листом, очередь опустеет.

## 4. Создайте два словаря

Правила получают `node["value"]`, а не первоначальный root. Создайте новый словарь для каждого потомка, присвойте их `node["left"]` и `node["right"]`. Не используйте один и тот же пустой словарь для обоих детей: изменения начнут распространяться между ветвями.

## 5. Добавьте новые задания

Положите обоих детей с level+1. Для height=3 порядок извлечения: корень; левый, правый; четыре внука. Заполните на бумаге столбцы «извлечённый узел», «оставшаяся очередь», «добавленные узлы» для правил x+1 и x−1.

## 6. Проверьте равенство результатов

На маленьких высотах сравните результат ЛР 3 и ЛР 4 оператором `==`: должны совпадать значения и структура. Отдельно проверьте, что разные ветви с одинаковыми значениями не стали одним объектом (`is not`). Запуск приложенных тестов: `python3 -m unittest -v`.

## 7. Уберите временную печать

Функция возвращает дерево. Печать размещайте снаружи — так код можно тестировать и позже использовать в ЛР 5. Сохраните её под именем `gen_bin_tree_iterative` в следующей работе.

## Самостоятельный шаг

Попробуйте заменить очередь стеком из списка: добавление через append, извлечение через pop. Предскажите порядок обработки. Проверьте, что готовое дерево не изменилось. Объясните отличие порядка построения от структуры результата.

Частые ошибки: сохранение чисел вместо словарей, отсутствие level+1, общий словарь детей, вызов рекурсивной функции «для удобства». Для защиты проследите три последовательных состояния очереди.
