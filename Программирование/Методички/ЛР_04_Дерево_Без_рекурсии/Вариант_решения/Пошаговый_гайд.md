# Построение с очередью

## 1. Не начинайте с полного дерева

Перенесите только создание корня и обработку height=0. Функция не должна вызывать сама себя ни прямо, ни через помощника. Вызов библиотечной очереди рекурсией не является.

## 2. Создайте очередь

Добавьте `(tree,1)`. Пока распечатайте значение извлечённого узла и его уровень. Убедитесь, что извлекается исходный словарь корня.

## 3. Определите, когда не нужны дети

Если level равен height, выполните continue. Для height=1 корень остаётся листом, очередь опустеет.

## 4. Создайте два словаря

Правила получают `node["value"]`, а не первоначальный root. Создайте новый словарь для каждого потомка, присвойте их `node["left"]` и `node["right"]`. Не используйте один и тот же пустой словарь для обоих детей: изменения начнут распространяться между ветвями.

## 5. Добавьте новые задания

Положите обоих детей с level+1. Для height=3 порядок извлечения: корень; левый, правый; четыре внука. Заполните на бумаге столбцы «извлечённый узел», «оставшаяся очередь», «добавленные узлы» для правил x+1 и x−1.

## 6. Проверьте равенство результатов

На маленьких высотах сравните результат ЛР 3 и ЛР 4 оператором `==`: должны совпадать значения и структура. Отдельно проверьте, что разные ветви с одинаковыми значениями не стали одним объектом (`is not`). Запуск приложенных тестов: `python3 -m unittest -v`.

## 7. Уберите временную печать

Функция возвращает дерево. Печать размещайте снаружи — так код можно тестировать и позже использовать в ЛР 5. Сохраните её под именем `gen_bin_tree_iterative` в следующей работе.

## Самостоятельный шаг

Попробуйте заменить очередь стеком из списка: добавление через append, извлечение через pop. Предскажите порядок обработки. Проверьте, что готовое дерево не изменилось. Объясните отличие порядка построения от структуры результата.

Частые ошибки: сохранение чисел вместо словарей, отсутствие level+1, общий словарь детей, вызов рекурсивной функции «для удобства». Для защиты проследите три последовательных состояния очереди.
