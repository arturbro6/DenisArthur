# Пошаговый гайд с нуля

## Как выполнять шаги в своей папке

Сначала прочитайте [основы Python](../../Начать_здесь/README.md). В VS Code откройте именно `Вариант_решения` этой работы через File → Open Folder. Если скачали репозиторий ZIP, сначала распакуйте архив; внутри окна GitHub файлы не запускаются. Оригинальные примеры уже лежат здесь: перед редактированием сохраните их копию в другой учебной папке.

Для промежуточных упражнений создайте рядом `practice.py`; для запуска используйте терминал VS Code:

```bash
python3 practice.py
```

Каждый новый блок с указанием «замените» полностью заменяет содержимое `practice.py`. Не склеивайте все упражнения в один файл. После изменения сохраните файл, запустите и сравните результат с указанным. В терминале не должно быть `>>>`.

## Шаг 1. Посмотреть пары

В practice.py введите и запустите:

```python
nums = [3, 2, 4]
for i in range(len(nums)):
    for j in range(i + 1, len(nums)):
        print(i, j, nums[i] + nums[j])
```

Ожидаемый вывод:

```text
0 1 5
0 2 7
1 2 6
```

Четыре пробела — тело первого цикла, восемь — второго. Вручную найдите строку с суммой 6: индексы 1 и 2.

## Шаг 2. Превратить поиск в функцию

Полностью замените practice.py:

```python
def add(nums, target):
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            if nums[i] + nums[j] == target:
                return [i, j]
    return None

print(add([3, 2, 4], 6))
print(add([3, 3], 6))
print(add([3], 6))
```

После запуска ожидается `[1, 2]`, `[0, 1]`, `None` на отдельных строках. Внутри if уже 16 пробелов: функция → цикл → цикл → условие. Последний return имеет четыре пробела и находится внутри функции, но снаружи циклов.

## Шаг 3. Сопоставить с add.py

Откройте готовый add.py. Первая функция делает тот же перебор, только с документацией и типами. При `python3 add.py` экран может остаться пустым: в этом файле нет демонстрационного print. Для показа импортируйте функцию в practice.py:

```python
from add import add
print(add([2, 7, 11, 15], 9))
```

Ожидается `[0, 1]`.

## Шаг 4. Проверить тесты и оптимизацию

Запустите `python3 -m unittest -v` в папке с add.py и test_add.py. Ожидается 11 проверок и OK. Теперь прочитайте add_fast: для [3, 3] сначала словарь пуст, после первого числа он {3: 0}; второе число находит дополнение 3 и возвращает [0, 1].

## Шаг 5. Сделать своё упражнение

Выберите шесть чисел, у которых пара расположена в конце. Запишите индексы вручную, затем вызовите add и сравните. Отдельно проверьте пустой список. Объясните, почему нельзя вернуть числа вместо индексов и почему None не находится внутри цикла.

## Дополнительный разбор после первых запусков

# Пошаговый разбор

## 1. Проверьте задачу вручную

Для `[3,2,4]` и суммы 6 выпишите пары позиций: (0,1) → 5; (0,2) → 7; (1,2) → 6. Значит, ответ `[1,2]`. Это ваш первый эталон, полученный без программы.

## 2. Создайте каркас

В `add.py` объявите `def add(nums, target):`. Пока верните `None`. Создайте рядом `test_add.py`. Напишите один тест на ручной пример. Он должен упасть: заглушка ещё не умеет искать пару.

## 3. Добавьте первый цикл

Перебирайте `i` от 0 до конца списка. Пока временно печатайте индекс и число. Убедитесь, что вывод начинается с нуля. Затем уберите диагностический `print`.

## 4. Добавьте второй цикл

Для каждого `i` перебирайте `j` от `i+1` до конца. Сначала объясните, почему старт с `i` даст ошибочный ответ для `[3]`, target=6. Сравните сумму значений, верните `[i,j]` при совпадении. `return None` оставьте после обоих циклов: иначе поиск завершится после первой неподходящей пары.

## 5. Запустите проверки

Из `Вариант_решения` выполните `python3 -m unittest -v`. В тестах допускайте оба порядка индексов. Добавьте пустой список, один элемент, отрицательные числа и повторяющиеся значения. Сравните свой код с приложенным `add.py` только после собственного первого варианта.

## 6. Разберите словарь

В файле есть отдельная `add_fast`. Для `[3,3]` порядок такой: сначала ищем дополнение в `seen`, потом запоминаем текущее число. Если сначала записать, а потом искать, первый элемент может ошибочно встретиться сам с собой. Проследите содержимое словаря по строкам.

## Самостоятельный шаг

Составьте список из шести чисел, у которого единственная подходящая пара находится в конце. Предскажите индексы и напишите тест. Не меняйте функцию специально под этот вход.

## Частые ошибки

- Возвращены числа вместо индексов — смотрите требуемый формат.
- `return None` внутри цикла — функция прекращает поиск слишком рано.
- Использование `list.index` на дубликатах — можно дважды получить первую позицию.
- Тест требует только `[0,1]` — обратный порядок тоже разрешён.

Для защиты: объясните `range(i+1, len(nums))`, расположение `return None` и цену двух вложенных циклов.
