# Списки, индексы и два цикла

Сначала прочитайте [основы Python](../../Начать_здесь/README.md). Эта часть объясняет синтаксис до применения в лабораторной.

## Список — значения по пронумерованным местам

```python
nums = [3, 2, 4]
print(len(nums))
print(nums[0])
```

Получится 3 и 3: длина три, а на позиции ноль лежит число три. Позиции этого списка: 0, 1, 2. `nums[3]` уже за границей и даст IndexError. В ответе задачи нужны позиции, а не сами значения.

```python
for i in range(len(nums)):
    print(i, nums[i])
```

`for` — повторить блок; `i` по очереди принимает индексы; `range(3)` даёт 0, 1, 2. Вторая граница range не включается. `range(1, 3)` даёт 1, 2.

Второй цикл `for j in range(i + 1, len(nums))` перебирает только позиции после i. Так индекс не соединяется сам с собой. Условие `nums[i] + nums[j] == target` сравнивает сумму двух чисел с нужной суммой. `return [i, j]` возвращает список из двух индексов и завершает весь вызов.

`return None` после обоих циклов означает «все пары закончились, совпадения нет». На уровне if он завершил бы поиск слишком рано. В аннотации `list[int] | None` вертикальная черта означает допустимый результат «список целых ИЛИ None».

## Быстрый вариант читать после обычного

`seen = {}` создаёт пустой словарь. `seen[value] = i` запоминает индекс для числа. `missing in seen` проверяет, есть ли число среди ключей; `seen[missing]` получает сохранённый индекс. `enumerate(nums)` выдаёт пару индекс/значение; `for i, value in ...` раскладывает пару в два имени. Сначала ищем дополнение, потом запоминаем текущее число, чтобы оно не встретилось само с собой.

## Дополнительный разбор после первых запусков

# Значение и индекс — разные вещи

В `nums = [4, 9, 2]` число `9` имеет индекс `1`: индексы начинаются с нуля. `nums[i]` получает значение на позиции `i`. Вернуть требуется позиции, а не сами числа.

```python
for i in range(len(nums)):
    print(i, nums[i])
```

`len(nums)` — длина; `range(3)` даёт 0,1,2. Цикл `for` повторяет блок для каждого индекса. Во вложенном цикле `j` начнётся с `i+1`: так один элемент не соединяется с собой и каждая пара проверяется один раз.

```python
if nums[i] + nums[j] == target:
    return [i, j]
```

`==` сравнивает, `=` присваивает. `return` сразу завершает функцию. `None` — отдельное значение «результата нет», не ноль и не пустая строка.

Перебор проверяет до n(n−1)/2 пар: время O(n²), дополнительная память O(1). Более быстрый способ использует словарь `значение → индекс`: для текущего x ищется уже встреченное `target-x`. Ожидаемое время O(n), память O(n). Сначала научитесь объяснять обычный перебор, затем переходите к словарю.

Официальная основа: [циклы и функции](https://docs.python.org/3/tutorial/controlflow.html), [списки и словари](https://docs.python.org/3/tutorial/datastructures.html).
