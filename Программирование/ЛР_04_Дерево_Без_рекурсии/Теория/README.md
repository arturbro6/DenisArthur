# Чем заменить рекурсивные вызовы

Нужно хранить ещё не обработанные узлы самостоятельно. **Стек** работает «последним положили — первым взяли»; **очередь** — «первым положили — первым взяли». В приложенном варианте выбрана очередь и построение по уровням.

```python
from collections import deque
queue = deque([(tree, 1)])
node, level = queue.popleft()
```

`deque` — двусторонняя очередь. Внутри лежит кортеж `(ссылка на узел, номер уровня)`. Запись `node, level = ...` распаковывает пару. `popleft()` удаляет первый элемент. `append(...)` добавляет в конец. В отличие от `list.pop(0)`, извлечение начала не требует сдвигать весь список.

```python
while queue:
    ...
```

Пустая очередь считается ложью, цикл завершается. `continue` пропускает оставшуюся часть одной итерации, не завершает всю функцию. У последнего уровня нет потомков.

В очередь кладутся ссылки на существующие словари. Изменение `node["left"]` становится видно в общем дереве: это тот же объект. Если вместо ссылки хранить только число, присоединить потомков к нужному родителю будет сложнее.

BFS — обработка по уровням; DFS — проход одной ветви до конца. Оба подхода могут строить одинаковое дерево. Здесь очередь в максимуме хранит O(2**h) узлов, само дерево тоже O(2**h). Итеративный вариант со стеком может уменьшить дополнительное хранение заданий, но не размер готового дерева.

[Документация deque](https://docs.python.org/3/library/collections.html#collections.deque).
