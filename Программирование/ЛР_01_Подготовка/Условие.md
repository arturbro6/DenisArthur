# Что требуется

Раздел ЛР 1 в курсе посвящён установке Python, выбору IDE и проверке доступа к Git-хостингу и Google Colab. В нём размещены книга установки и входное тестирование. Отдельной вычислительной задачи для этой ЛР на просмотренной странице нет.

Нужно установить Python, выбрать редактор (например VS Code), уметь запускать `.py`-файл и проверить учётную запись GitHub. Входное тестирование проходится самостоятельно в Moodle.

Для последующих работ курс требует отдельную папку на ЛР, исходный код, отдельный файл тестов и README с авторством. На странице также есть более ранняя инструкция про GitHub Classroom: если преподаватель выдаст Classroom-ссылку, используйте её для сдачи.

Источник задания: [раздел ЛР 1](https://moodle.herzen.spb.ru/course/view.php?id=1490), [книга установки](https://moodle.herzen.spb.ru/mod/book/view.php?id=1294072).

Формулировка здесь изложена своими словами. При изменении требований преподавателем сверяйтесь со страницей Moodle и исходным файлом по ссылке.
