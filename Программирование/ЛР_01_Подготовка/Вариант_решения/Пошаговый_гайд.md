# Шаг за шагом

## 1. Проверьте Python

Откройте терминал VS Code: Terminal → New Terminal. На Mac выполните `python3 --version`, на Windows — `py --version`. Если версия уже выводится, повторно устанавливать Python не нужно. Если команды нет, установите Python 3 с [python.org](https://www.python.org/downloads/), как описано в книге Moodle. На Windows обратите внимание на PATH; на Mac выберите установщик для macOS.

## 2. Откройте именно папку

Создайте собственную рабочую папку, выберите File → Open Folder. Создайте `hello.py`. Проверьте `pwd` на Mac или `Get-Location` в PowerShell: терминал должен находиться в папке с файлом.

## 3. Напишите маленькую функцию

Напишите `greet(name)` из теории. Ниже добавьте вызов `print(greet("Артур"))`. Сначала предскажите вывод, затем запустите `python3 hello.py` (Windows: `py hello.py`). Поменяйте имя и проверьте, что изменилось.

## 4. Отделите запуск от импорта

Посмотрите `hello.py` в этой папке. Условие `if __name__ == "__main__":` означает: выполнять этот блок только при прямом запуске файла. При импорте в тесты приветствие не печатается.

## 5. Запустите первый тест

Откройте `test_hello.py`. `assertEqual` сравнивает полученный результат с ожидаемым. Запустите из этой папки `python3 -m unittest -v`. Сначала временно измените ожидаемое приветствие и увидьте падение; затем верните правильное значение. Так становится понятно, что тест действительно что-то проверяет.

## 6. Подготовьте Git

В собственном проекте выполните `git init`, затем создайте `.gitignore` с `.venv/`, `__pycache__/` и `.DS_Store`. Выполните `git status` и убедитесь, что служебные файлы не попали в список. Авторство укажите в README. Сообщения коммитов для этого общего репозитория оставляем пустыми; для собственного проекта следуйте требованиям преподавателя.

## Самостоятельный шаг

Добавьте функцию, которая возвращает приветствие с восклицательным знаком, и отдельный тест. Объясните разницу между `return` и `print` без запуска.

## Если не работает

`can't open file` — неверная папка или имя файла. `ModuleNotFoundError: hello` — тест находится не рядом с модулем или запущен из другой папки. `IndentationError` — проверьте пробелы, не смешивайте табы и пробелы.

Готовность: можете создать файл, выполнить его, запустить тест, показать `git status` и объяснить каждую строку примера.
